# Test files

All secrets in these files are made up. The passwords are in the test code.

| File | Made with | Format | Password |
|---|---|---|---|
| `SimplePasswordV4.kdbx` | From pidamg/keepass-dotnet @ 7fa3f9a (MIT) | KDBX 4.0, Argon2d, AES-256 | `password123` |
| `SimplePasswordV3_ChaCha20.kdbx` | From pidamg/keepass-dotnet @ 7fa3f9a (MIT) | KDBX 3.1, AES-KDF, ChaCha20 | `password123` |
| `Argon2id-ChaCha20.kdbx` | KeePassXC GUI | KDBX 4.0, Argon2id (2 iterations, 1 MiB, parallelism 4), ChaCha20 | `password123` |
| `Argon2d-Twofish.kdbx` | KeePassXC GUI | KDBX 4.0, Argon2d (2 iterations, 1 MiB), Twofish | `password123` |
| `AES-KDF.kdbx` | KeePassXC GUI | KDBX 4.1 (custom icon), AES-KDF (2 rounds), AES-256, uncompressed | `password123` |
| `mapping.kdbx` | `keepassxc-cli import` of `mapping.xml` | KDBX 3.1, AES-KDF, AES-256, Salsa20 | `mapping-pw` |
| `mapping-v2.kdbx` | `mapping.kdbx` with the `TopLevel` password set to `changed-secret` | same | `mapping-pw` |
| `duplicates.kdbx` | `keepassxc-cli import` of `duplicates.xml` | same | `duplicates-pw` |
| `keyfile-only.kdbx` + `keyfile.keyx` | `keepassxc-cli db-create --set-key-file` | KDBX 3.1, XML v2 key file | (none) |
| `password-and-keyfile.kdbx` | `keepassxc-cli db-create -p --set-key-file`, same key file | KDBX 3.1 | `combo-pw` |

`mapping.xml` and `duplicates.xml` are generated by `gen.py` (`python3 gen.py mapping`), then imported
with KeePassXC 2.8.0:

```sh
keepassxc-cli import -p -t 100 mapping.xml mapping.kdbx
```

keepassxc-cli cannot choose the cipher, KDF or format version, so the KDBX 4 files were made in the
KeePassXC 2.8 GUI with low KDF settings to keep the tests fast.
